# Messages in your language (i18n)

Every script of this repository is written in English, and **every message a person reads** (progress,
questions, summaries, windows, fish functions, the GRUB theme's texts, fastfetch's labels) goes through a
translation catalog. With the Spanish catalog the output is the original one, word for word (checked with
`diff` against the original scripts: `update-system --summary`, `audit-void.sh`, `ssh-survey.sh`…).

**What is never translated:** what programs or this documentation read back — service logs
(`~/.local/state/steam-game-mode.log`, `/run/switch-mode.log`…), status tokens (`STILL_NEEDED`, `OK`/`WARNING`
inside `update-system`, `RESULT …`), lines that are grepped, file names. Those are fixed in English, so a
recipe's check works in any language.

## How the language is chosen

The first of `LANGUAGE`, `LC_ALL`, `LC_MESSAGES`, `LANG` (only the language part: `es_MX.UTF-8` → `es`);
under `sudo` with an empty environment, `LANG` from `/etc/locale.conf` (Void sets it there). `C`, `POSIX`,
`en` or no catalog for that language → English.

Catalogs, first found: `$VOID_LEGION_LOCALE_DIR`, `~/.local/share/void-legion/locale`,
`/usr/local/share/void-legion/locale`, and the clone's `locale/`.

## The pieces

| File | For |
|---|---|
| `locale/<lang>/messages.po` | the catalog (gettext PO: `msgid` = the English text, `msgstr` = the translation) |
| `lib/i18n.sh` | `t FORMAT ARGS…` for sh/bash (POSIX) |
| `lib/void_legion_i18n.py` | `_("…")` for Python |
| `common/fish/functions/__vl_t.fish` | `__vl_t FORMAT ARGS…` for fish |
| `install/install-i18n.sh` | copies them to `~/.local/share/void-legion` (as user) or `/usr/local/…` (with sudo) |

Scripts run from the clone find `lib/` by walking up from their own folder. Pieces that the installers
write into the system (launchers, `/usr/local/bin/…`, `~/.local/bin/…`) use the installed copies; without
them they show English. `ssh-setup` sends the local catalog to the other machine together with the x-ray
(see [ssh-setup.md](ssh-setup.md)).

## Rules for writing messages

- `t "Copying %s to %s" "$a" "$b"` — the format is the `msgid`; arguments go as `%s`, never pasted into the
  format (paths with `%` or backslashes would break it). A literal `%` is `%%`.
- Python: `_("opened with %s sources") % n`.
- One message = one sentence or line; do not build sentences from pieces (word order changes between languages).
- If two places need the same English word with different translations (e.g. gender in Spanish), use
  different `msgid`s (`"unknown"` / `"not known"`).

## Adding a language (e.g. Portuguese)

```bash
mkdir -p locale/pt
cp locale/es/messages.po locale/pt/messages.po
# translate every msgstr (leave msgid untouched); empty msgstr = English for that message
msgfmt -c -o /dev/null locale/pt/messages.po     # optional check (package gettext)
bash install/install-i18n.sh && sudo bash install/install-i18n.sh
```

With `LANG=pt_BR.UTF-8` the scripts speak Portuguese. Commands, options and file names stay in English
in every language (no translated or old Spanish aliases: removed on 2026-10-13, the user's decision).
