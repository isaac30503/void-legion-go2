# Library art

Steam's library shows cover, banner, hero, logo and icon for each game; non-Steam games get theirs here.

## xterm

`common/steam/art-xterm/generate.py` (without root; `rsvg-convert`, the system's `python3-Pillow`, `fc-match`):
Papirus' terminal icon at 1024 px on a radial gradient with halo and scan lines, "XTERM" in JetBrainsMono Nerd Font
Mono bold, Super Game Bro palette. It finds in `shortcuts.vdf` the shortcut whose `Exe` contains `xterm`, takes its
unsigned `appid` (`appid & 0xFFFFFFFF`) and writes in `~/.local/share/Steam/userdata/@STEAM_ACCOUNT_ID@/config/grid/`
`<appid>p.png` (600×900), `<appid>.png` (920×430), `<appid>_hero.png` (1920×620), `<appid>_logo.png` (1200×400),
`<appid>_icon.png` (512×512) and `<appid>.json` (logo bottom left, 50 %).

```bash
python3 "$B/common/steam/art-xterm/generate.py"      # with Steam closed (on the desktop); then open Steam
```

**The quick menu's icon** comes from the `icon` field of `shortcuts.vdf`, not from `grid/`: with Steam **closed** the
generator puts `~/.local/share/icons/steam-shortcuts/xterm-color-256.png` there (leaving `shortcuts.vdf.bak`; with
Steam open, Steam overwrites it on exit and the generator warns with `!!`). Alternative from Steam's interface: *xterm →
Propiedades → Acceso directo* (*Properties → Shortcut*) → the icon box → that file.

## Firefox and Vesktop

- **Firefox:** chosen by hand with the **SteamGridDB** plugin of [Decky](5-decky.md) (Firefox → SteamGridDB → choose).
- **Vesktop:** generated by `common/steam/art-vesktop/generate.py` ([Vesktop](../7-apps/2-vesktop.md)).
